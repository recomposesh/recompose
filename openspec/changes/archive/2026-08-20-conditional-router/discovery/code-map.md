- `packages/engine/src/routing/route-node-key.ts` (outside FSD (packages/engine, routing core)) — symbols: RouteNodeAddress, routeNodeKey. The slug plus virtual model plus route node key that every per-node memory uses, and the key shape a branch decision memory would extend with a conversation fingerprint.

- `packages/engine/src/gateway-routing-memory.ts` (outside FSD (packages/engine, per-gateway runtime memory)) — symbols: RoutingMemory, routingMemory.
