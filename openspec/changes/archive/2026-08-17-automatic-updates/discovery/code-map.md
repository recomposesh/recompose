# Code map

- `openspec/changes/automatic-updates/specs/updates/spec.md` (spec (outside FSD)) — symbols: An update arrives through the channel that installed the app, A downloaded update waits for the person, A failed update check stays out of the way. The three requirements this map serves, covering channel gating, a standing restart affordance, and a silent failed check.
- `docs/adr/0133-an-update-arrives-through-the-channel-that-installed-it.md` (docs (outside FSD)) — symbols: none. The accepted decision that pins electron-updater, the process.windowsStore and process.env.APPIMAGE gates, win.publisherName, and the draft-release publish gate.
- `apps/desktop/src/main/index.ts` (main process (outside FSD)) — symbols: startRecompose, answerEveryChannel, recomposeHome, registerAppLifecycle. The boot sequence where the launch check attaches, after createMainWindow(HOME_ROUTE) and beside the existing tray and menu wiring.
- `apps/desktop/src/main/app-lifecycle.ts` (main process (outside FSD)) — symbols: registerAppLifecycle. Owns whenReady, activate, before-quit and window-all-closed, so the launch check hangs off start and the repeat interval must be cleared in dispose.
- `apps/desktop/src/main/ipc/push-events.ts` (main process (outside FSD)) — symbols: pushSettingsChanged, pushDevtoolsToggle, pushLaunchRefused, pushAccountsChanged. The one-way push surface toward the renderer, and the file a new update-ready push joins as a sibling of these nine.
- `apps/desktop/src/main/ipc/register-ipc.ts` (main process (outside FSD)) — symbols: assembleIpcHandlers, registerIpcHandlers, HandlerWiring. Where a new updater handler group spreads into the assembled handler map, following createSystemIpcHandlers and createUsageIpcHandlers.
- `apps/desktop/src/main/ipc/dispatch.ts` (main process (outside FSD)) — symbols: IpcHandlers, ipcChannelNames, dispatchIpc. The channel-name list and validating dispatcher every request channel passes through, so a restart-now channel registers here.
- `apps/desktop/src/main/ipc/system-ipc.ts` (main process (outside FSD)) — symbols: SystemIpcContext, SystemIpcHandlers, createSystemIpcHandlers. The nearest existing handler group by shape, answering system:get from an observed platform state, and the model for an updater group.
- `packages/contracts/src/ipc.ts` (contracts package (outside FSD)) — symbols: ipcChannels, ipcEvents, IpcChannel, IpcEvent, IpcEventPayload, RecomposeIpc, RecomposeIpcEvents, systemStateSchema, SystemState. The single Zod source of truth for every channel and event, and the file that gains the update-ready event payload plus a restart request channel.
- `packages/contracts/src/index.ts` (contracts package (outside FSD)) — symbols: ./ipc, ./settings, ./ipc-result. The package barrel that re-exports the IPC module, so a new schema reaches main, preload, and renderer through one import.
- `apps/desktop/src/preload/index.ts` (preload bridge (outside FSD)) — symbols: bridgeEntry, eventEntry, recompose, recomposeEvents. The contextBridge surface listing every channel and event by name, so a new update event needs an entry in recomposeEvents or the renderer cannot hear it.
- `apps/desktop/src/preload/index.d.ts` (preload bridge (outside FSD)) — symbols: none. The window.recompose and window.recomposeEvents typings the renderer reads against.
- `apps/desktop/src/renderer/src/app/routes/__root.tsx` (app) — symbols: Route, RootLayout, RouterAppContext, usePushedCaches, useDevtoolsAsked, surfaceMain. The only mount that outlives navigation between pages, so the standing restart affordance and the update event subscription belong here.
- `apps/desktop/src/renderer/src/app/routes/-app-toolbar.tsx` (app) — symbols: AppToolbar. The window strip with leading and trailing act slots, the composition point if the affordance rides the toolbar rather than the sidebar.
- `apps/desktop/src/renderer/src/app/routes/-app-sidebar.tsx` (app) — symbols: AppSidebar. The persistent sidebar with its system nav group, the alternative home for an affordance that must survive every route change.
- `apps/desktop/src/renderer/src/shared/api/settings.ts` (shared) — symbols: bindSettingsToCache. The reference pattern for turning a main-process push into a query cache write, which an update-ready binding copies.
- `apps/desktop/src/renderer/src/shared/api/engine.ts` (shared) — symbols: bindEngineStatesToCache. The second event-to-cache binding, showing the unsubscribe-returning shape usePushedCaches expects.
- `apps/desktop/src/renderer/src/shared/api/system.ts` (shared) — symbols: systemQueryOptions, useOpenConfigFolder. The system-state query and its mutation hook, the closest sibling for a new update-state query and a restart mutation.
- `apps/desktop/src/renderer/src/shared/api/index.ts` (shared) — symbols: ./system, ./settings, ./engine. The api segment public API, the only path higher layers import from, so any new update module exports through it.
- `apps/desktop/src/renderer/src/shared/ui/index.ts` (shared) — symbols: Badge, Button, StatusChip, ToolbarButton. The ui segment barrel, where a new affordance component registers as ui/<name>/<name>.tsx beside its required stories sibling.
- `apps/desktop/src/renderer/src/pages/settings/ui/general-section/general-section.tsx` (pages) — symbols: GeneralSection. The settings surface that would carry a version or update row if the design places one beyond the standing affordance.
- `apps/desktop/electron-builder.yml` (packaging (outside FSD)) — symbols: mac, nsis, linux, publish, deb, dmg. Carries notarize false today plus the NSIS, AppImage and deb targets, and needs the notarize flip, the universal mac build, the zip target, win.publisherName, and an appx target.
- `apps/desktop/package.json` (packaging (outside FSD)) — symbols: dependencies, build:mac, build:win, build:linux. electron-updater lands in dependencies rather than devDependencies because the packaged app loads it at runtime.
- `.github/workflows/release.yml` (CI (outside FSD)) — symbols: draft. The per-OS matrix build and the draft job that creates the GitHub release, the gate ADR-0133 turns into the moment an update reaches anyone, and where the APPLE and SignPath secrets bind.
- `apps/desktop/e2e/fixtures.ts` (e2e (outside FSD)) — symbols: test, Given, When, Then, inheritedEnv. The Electron launch fixture and BDD bindings a scenario needs, including the env seam where APPIMAGE or a store flag would be faked.
- `apps/desktop/e2e/steps/settings-screen.steps.ts` (e2e (outside FSD)) — symbols: none. The naming and structure precedent for a new updates steps file beside a new features/updates folder.
- `apps/desktop/src/main/ipc/system-ipc.ts` (gap) — symbols: createSystemIpcHandlers. Gap, systemStateSchema carries fileBrowser, loginItem, loginItemEnabled, menuBarVisible and configFolder but no version, so nothing today can name the running or waiting version to the renderer.
- `apps/desktop/src/main` (gap) — symbols: none. Gap, a repository-wide search for electron-updater, autoUpdater and checkForUpdates returns nothing in src, package.json, contracts or release.yml, so the whole updater subsystem is greenfield with no file to extend.
