# Code map

- `openspec/changes/usage-screen/manifest.md` (openspec change (not renderer)) — symbols: none. GAP: the change directory holds only this manifest (front matter: tier standard, phase discovery, branch worktree-usage-screen) plus .openspec.yaml, so no proposal or spec delta states the usage screen's intended readings; the map below is inferred from the shipped placeholder and the telemetry that already reaches the renderer.
- `apps/desktop/src/renderer/src/pages/usage/ui/usage-page/usage-page.tsx` (pages) — symbols: UsagePage. The whole surface today: a title plus a 'No requests yet' card promising rate, latency, tokens, and spend; every real reading replaces or wraps this component.
- `apps/desktop/src/renderer/src/pages/usage/index.ts` (pages) — symbols: UsagePage. The slice's only public API line; new usage components stay behind it rather than being imported by path from the route.
- `apps/desktop/src/renderer/src/pages/usage/ui/usage-page/usage-page.stories.tsx` (pages) — symbols: NothingServedYet, DarkScheme. Existing story pair for the empty state; the mandated sibling for any new ui/ component in this slice follows the same preview.meta shape and dual-scheme habit.
- `apps/desktop/src/renderer/src/pages/usage/ui/usage-page/usage-page.browser.test.tsx` (pages) — symbols: none. The slice's behavior spec, currently pinning the empty state; the TDD entry point for served-request readings.
- `apps/desktop/src/renderer/src/app/routes/usage.tsx` (app) — symbols: Route. File route /usage wiring UsagePage plus PageError; the place any loader that warms a usage query would land.
- `apps/desktop/src/renderer/src/app/routes/-app-sidebar.tsx` (app) — symbols: AppSidebar. Owns the System group's Usage nav row (to="/usage", arrow-driven navigate) — touched only if the screen gains sub-navigation or a live badge.
- `apps/desktop/src/renderer/src/app/routes/__root.tsx` (app) — symbols: Route, RouterAppContext. Calls bindEngineLogsToCache(queryClient) app-wide, which is why every gateway's rows sit in the query cache regardless of which canvas is open — the load-bearing fact that makes a machine-wide usage screen possible without a new IPC channel.
- `apps/desktop/src/renderer/src/shared/api/engine-logs.ts` (shared) — symbols: engineLogsQueryOptions, bindEngineLogsToCache. Per-gateway row cache keyed ['engine-logs', slug] with queryFn skipToken and merge-by-row-id; a cross-gateway usage view must fan out over slugs because no all-gateways key exists.
- `apps/desktop/src/renderer/src/shared/api/engine.ts` (shared) — symbols: engineStatesQueryOptions, engineTrafficQueryOptions, bindEngineTrafficToCache, gatewayStateIn. Running/stopped state and last-outcome-per-virtual-model traffic; the source for 'which gateways are live' framing on the usage screen.
- `apps/desktop/src/renderer/src/shared/api/gateways.ts` (shared) — symbols: gatewaysQueryOptions. The gateway list the usage screen iterates to reach each per-slug log cache and to name rows by gateway.
- `apps/desktop/src/renderer/src/shared/api/accounts.ts` (shared) — symbols: accountsQueryOptions, bindAccountChangesToCache. Account registry needed to render a row's accountId as an account name, the same resolution the log drawer performs.
- `apps/desktop/src/renderer/src/shared/api/index.ts` (shared) — symbols: none. Segment barrel re-exporting engine, engine-logs, gateways, and accounts; the import surface for the usage slice.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/lib/traffic-aggregates.ts` (pages) — symbols: trafficAggregates, TrafficAggregates. Pure one-minute reading of rows against an instant (the canvas footer's rate, latency, errors, client apps); reusing it from pages/usage would be a forbidden same-layer cross-import, so this is the prime extraction candidate.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/traffic-footer/footer-readings.ts` (pages) — symbols: compactCount, readDuration, pluralized. Display formatting for counts, durations, and pluralized nouns; same cross-import bind as traffic-aggregates, and a natural shared/lib move if the usage screen shows the same units.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/traffic-footer/traffic-footer.tsx` (pages) — symbols: TrafficFooter. The shipped precedent for a live readings strip (props slug, nodes, wires); the usage screen's cards are the machine-wide restatement of it.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/lib/log-scope.ts` (pages) — symbols: LogSubject, requestInFlight, requestFailed, logScope. Single authority for whether a row is in flight or failed; a usage error count must read from the same rule rather than re-deriving it from status.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/log-row/logged-request.ts` (pages) — symbols: LOG_ROW_HEIGHT, servedAt, tookFor, servedByAccount, servedByProvider, copiedRow. Row-level presentation (timestamp, duration, account and provider naming) if the usage screen lists recent requests rather than only aggregates.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/lib/use-canvas-clock.ts` (pages) — symbols: none. The display tick that drives the footer's rolling window; a live usage screen needs the same clock ownership pattern instead of recomputing on every push.
- `apps/desktop/src/renderer/src/shared/ui/index.ts` (shared) — symbols: Badge, Chip, Icon, SegmentedControl, StatusChip, StatusIndicator, PageError. UI kit barrel; a usage screen with range switching, per-gateway rows, and status marks composes from these before adding anything new.
- `apps/desktop/src/renderer/src/shared/testing/fake-engine-pushes.ts` (shared) — symbols: listenForEngineLogs, emitEngineLogs, replayEngineLogs, emitEngineTraffic, forgetEngineLogsListeners. The push seam stories and browser tests use to drive rows into the cache; every non-empty usage state is authored through these.
- `apps/desktop/src/renderer/src/shared/testing/fake-bridge.ts` (shared) — symbols: installFakeBridge, BridgeParameters. Fake window.recompose bridge; gateway and account fixtures for usage specs arrive through its parameters.
- `apps/desktop/src/renderer/src/app/testing/render-app.tsx` (app) — symbols: renderAt. renderAt('/usage', parameters) is the entry every usage browser test uses to mount the real route tree.
- `packages/contracts/src/engine-logs.ts` (contracts package (outside FSD)) — symbols: logRowSchema, LogRow, logBatchSchema, LogBatch. The row contract that bounds what the screen can show: at, gateway, virtualModel, origin, status, optional durationMs and a single optional tokens count, clientKey digest, optional failure. GAP: no input/output token split and no cost or spend field, so the placeholder's 'spend' promise has no contract behind it today.
- `packages/contracts/src/engine-traffic.ts` (contracts package (outside FSD)) — symbols: requestOutcomeSchema, RequestOutcome, gatewayTrafficSchema, GatewayTraffic. Last-outcome-per-virtual-model record (live, served, failed with status and detail); a latest-state view, explicitly not a history.
- `packages/contracts/src/ipc.ts` (contracts package (outside FSD)) — symbols: ipcChannels, ipcEvents, IpcChannel, RecomposeIpc, RecomposeIpcEvents. Channel and event tables carrying 'engine:logs', 'engine:traffic', and 'engine:replay-logs'; any new usage-specific request or push is registered here first.
- `apps/desktop/src/preload/index.ts` (preload bridge (outside FSD)) — symbols: none. Mirrors the contract tables into the bridge (bridgeEntry for 'engine:replay-logs', eventEntry for 'engine:logs' and 'engine:traffic'); a new channel fails at runtime until it is added here too.
- `apps/desktop/src/main/ipc/engine-ipc.ts` (main process (outside FSD)) — symbols: EngineIpcContext, EngineIpcHandlers, createEngineIpcHandlers. Where engine-facing handlers including the logs replay are assembled; the landing spot for any main-side usage query.
- `apps/desktop/src/main/engine-host/logs-ledger.ts` (main process (outside FSD)) — symbols: openLogsDesk, LogsDesk, LOGS_RETAINED_MAX, LOGS_BACKFILL_CHUNK. Main's retained row buffer (10,000 rows, 500-row backfill chunks); the retention ceiling that caps any window the usage screen can look back over.
- `apps/desktop/src/main/engine-host/traffic-ledger.ts` (main process (outside FSD)) — symbols: openTrafficDesk, TrafficDesk, TRAFFIC_PUSH_MS. Coalesces engine outcomes into the 16ms traffic push; sets the cadence a live usage reading inherits.
- `apps/desktop/src/main/engine-host/engine-spend.ts` (main process (outside FSD)) — symbols: SpendGrantFor, answerSpendRequest. The only spend machinery that exists, and it grants budget per gateway and virtual model rather than accruing spend; a spend reading on the usage screen needs new accrual, not a read of this.
- `packages/engine/src/gateway-traffic.ts` (engine package (outside FSD)) — symbols: openServingTurn, subscribeToLogRows, watchingTraffic, noteUnreadableRequest, NoteTraffic, LogRowListener. Engine-side origin of every log row and outcome; any new field the usage screen needs (token split, cost) is populated here first.
- `packages/engine/src/provider/provider-usage.ts` (engine package (outside FSD)) — symbols: ProviderUsage, emptyProviderUsage, providerUsageFrom. Parses token usage out of a provider answer per dialect; the richest token data in the system and the source to widen the row contract from.
- `packages/engine/src/provider/provider-observability.ts` (engine package (outside FSD)) — symbols: ProviderObservability, ProviderObservationSpan, providerObservability, providerUsageFrom, ProviderRequestLog. Spans that pair a provider attempt with its usage reading; the join point between an attempt and the tokens it consumed.
- `packages/engine/src/provider/telemetry-feed.ts` (engine package (outside FSD)) — symbols: ProviderAttempt, AttemptInFlight, subscribeToProviderAttempts, attemptFor, tellingReaders. Per-attempt telemetry stream (finer grained than a log row); the feed to tap if usage needs per-target attempt and retry counts.
- `steiger.config.ts` (FSD lint config (outside FSD)) — symbols: none. Governs insignificant-slice and layer rules; extracting traffic-aggregates or footer-readings out of gateway-canvas is checked against this config.
