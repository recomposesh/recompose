# Code map

- `openspec/changes/landing-docs-site/proposal.md` (change proposal (no FSD layer)) — symbols: Locked decisions, Capabilities, Impact. Locks the four decisions the code map answers to: apps/web in this monorepo, TanStack Start carrying Fumadocs, a static Cloudflare build, and landing plus a first docs set in one release.
- `openspec/changes/landing-docs-site/specs/website/spec.md` (capability spec (no FSD layer)) — symbols: Requirement: The public site serves as files, Requirement: One application holds both public surfaces, Requirement: The hero reveals the scene under the pointer. The three requirements the build must satisfy; on archive this becomes a fifteenth capability beside the fourteen already under openspec/specs/.
- `openspec/changes/landing-docs-site/manifest.md` (change manifest (no FSD layer)) — symbols: tier, phase, branch. Pins tier full, phase discovery, and branch worktree-landing-docs-site for the cycle.
- `apps` (workspace root (no FSD layer)) — symbols: desktop. GAP: apps/web does not exist; this directory holds desktop alone, so every file of the site is new and nothing in-tree can be cited for it yet.
- `pnpm-workspace.yaml` (workspace root (no FSD layer)) — symbols: packages, allowBuilds, minimumReleaseAge, minimumReleaseAgeExclude. The apps/* glob already admits a second application, but minimumReleaseAge of 4320 minutes means fresh Fumadocs or TanStack Start releases need an explicit exclude line.
- `package.json` (repository gates (no FSD layer)) — symbols: scripts.build, scripts.dev, scripts.typecheck, scripts.lint:fsd, scripts.lint:boundaries, scripts.lint:dead, scripts.lint:dup, scripts.lint:spell, scripts.lint:prose, scripts.lint:stories, scripts.lint:licenses, scripts.typecheck:root-configs. lint:fsd hardcodes apps/desktop/src/renderer/src, and typecheck:workflows and typecheck:root-configs both run tsc through the desktop filter, so widening to a second app edits this file first.
- `turbo.json` (repository gates (no FSD layer)) — symbols: tasks.build, tasks.typecheck, tasks.dev, tasks.lint, tasks.test. build outputs list only dist/** and out/**, so the static site's emitted directory must join that list or every CI run rebuilds it uncached.
- `apps/desktop/package.json` (workspace member manifest (no FSD layer)) — symbols: name, scripts.build, scripts.dev, scripts.typecheck, scripts.lint, imports. The template the new site manifest mirrors: the turbo task names, the split typecheck, and the #* subpath imports convention.
- `.oxlintrc.json` (repository gates (no FSD layer)) — symbols: settings.tailwindcss.entryPoint, ignorePatterns, overrides. The Tailwind entry point is a single desktop stylesheet path, so a second Tailwind root has no class validation until this key admits it; routeTree.gen.ts is already globally ignored.
- `.oxfmtrc.json` (repository gates (no FSD layer)) — symbols: sortTailwindcss.stylesheet, sortImports.groups. Class sorting resolves against apps/desktop/src/renderer/src/app/styles/main.css alone, which is the same single-stylesheet assumption as the linter.
- `.dependency-cruiser.cjs` (repository gates (no FSD layer)) — symbols: renderer-isolated, desktop-not-into-engine, headless-scope, engine-only-contracts, no-orphans. Every boundary rule keys on ^apps/desktop/ paths and one tsConfig at apps/desktop/tsconfig.web.json; the spec's rule that the site must not import the desktop app lands here as a new forbidden rule.
- `knip.json` (repository gates (no FSD layer)) — symbols: workspaces. Dead-code detection is per workspace with explicit entry lists, so the site needs its own block for route files and the generated route tree.
- `cspell.json` (repository gates (no FSD layer)) — symbols: ignorePaths, dictionaries, ignoreRegExpList, words. Authored docs pass the spell gate; the ignoreRegExpList already skips base64 runs, which is why the prototype's embedded media never tripped it.
- `cspell-words.txt` (repository gates (no FSD layer)) — symbols: recompose-words. The committed accept list the custom dictionary reads; new site and docs vocabulary lands here through the PR diff.
- `.vale.ini` (repository gates (no FSD layer)) — symbols: BasedOnStyles, MinAlertLevel, Vocab. The prose gate binds the [*.md] glob only, so Fumadocs content authored as .mdx sits outside every rule until a section names that extension.
- `lefthook.yml` (repository gates (no FSD layer)) — symbols: pre-commit, pre-push, protect-main. The local gate order that every site commit passes: boundaries, fsd, dead, dup, spell, prose, fmt, typecheck on commit and the story check on push.
- `steiger.config.ts` (repository gates (no FSD layer)) — symbols: defineConfig, fsd.configs.recommended. The FSD linter config is path agnostic, so the site's own src root joins the gate through the lint:fsd script rather than through this file.
- `.jscpd.json` (repository gates (no FSD layer)) — symbols: threshold, minTokens, ignore. Duplication threshold sits at zero over apps and packages, so any hero code ported alongside a desktop equivalent has to differ or be shared outright.
- `.github/workflows/ci.yml` (CI (no FSD layer)) — symbols: changes, check, prose, meta, coverage-upload, ci-success. The check job runs turbo across the whole workspace then eleven root gate scripts, and the coverage upload names three fixed lcov paths, so a fourth workspace changes both.
- `apps/desktop/src/renderer/src/app/styles/primitives.css` (app) — symbols: --gray-950, --blue-500, --white. Tier one of the two-tier token scheme, the raw palette; the site needs these values and they currently live inside the one application it must not import from.
- `apps/desktop/src/renderer/src/app/styles/theme.css` (app) — symbols: --font-sans, --color-ink, --color-surface-content, --text-body, --radius-chip. Tier two, the Tailwind 4 @theme layer of semantic tokens the site reproduces so both surfaces carry the same brand.
- `apps/desktop/src/renderer/src/app/styles/main.css` (app) — symbols: @import 'tailwindcss', app-drag, app-no-drag. The desktop Tailwind entry point the site mirrors, minus the Electron-only drag regions and the transparent window background.
- `apps/desktop/src/renderer/src/app/router.tsx` (app) — symbols: createAppRouter, AppRouterOptions. The TanStack Router creation and module registration pattern the site's TanStack Start router follows.
- `apps/desktop/src/renderer/src/app/routes/__root.tsx` (app) — symbols: Route, RouterAppContext. The root route with typed context, the shape the site's own root route copies for its Fumadocs layout.
- `apps/desktop/src/renderer/src/app/query-client.ts` (app) — symbols: createQueryClient. Query client factory mounted in main.tsx; the static site needs no runtime fetching, so this is a reference for the router wiring rather than a dependency.
- `apps/desktop/src/renderer/src/app/routeTree.gen.ts` (app) — symbols: FileRoutesByFullPath, FileRoutesById, FileRoutesByTo. The generated route tree that knip and oxlint both ignore by name; the site generates the same artifact and needs the same ignores.
- `README.md` (docs (no FSD layer)) — symbols: Features, How it works, Building from source. The only in-repo writing aimed at a person rather than a builder, and the nearest source material for the first docs set on installing and connecting a provider.
- `docs/adr/0009-two-tier-design-tokens.md` (docs (no FSD layer)) — symbols: Two-tier design tokens on Tailwind v4. The token contract the site inherits, and the record to cite when the tokens move out of the desktop app.
- `docs/adr/README.md` (docs (no FSD layer)) — symbols: 0103. The ADR index a site-stack record joins; the highest number in the tree is docs/adr/0103-the-patch-gate-asks-for-ninety.md, so the new record takes 0104.
- `designs` (design assets (no FSD layer)) — symbols: recompose.pen, dot-grid.glsl, fonts. GAP: the hero prototype the proposal calls already built is not in the tree; greps for a canvas render loop and for base64 media returned nothing, and this directory holds only the pen file, one shader, and the font cache.
- `designs/fonts/localhost` (design assets (no FSD layer)) — symbols: d331981c36b411ad.woff2, 0760001a28494f09.woff2, 9bb873ba281e355a.woff2, ac90dc6599af0936.woff2. GAP: the brand typeface exists only as four hashed woff2 files from a Typekit localhost cache, with no kit id, license terms, or @font-face rule anywhere in the tree.
- `BRAINSTORM-NOTES.md` (docs (no FSD layer)) — symbols: design-system/library/. GAP: this file and the proposal both point at design-system/ as the shared token source, but no such directory exists; the tokens sit inside apps/desktop, the one app the spec forbids the site to import from.
