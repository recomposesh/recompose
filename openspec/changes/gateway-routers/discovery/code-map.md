# Code map

- `openspec/changes/gateway-routers/proposal.md` (openspec change (outside the renderer, no FSD layer)) — symbols: none. The proposal that scopes the work: router node, two modes, a new gateway schema version with a migration, and a second serving attempt.
- `openspec/changes/gateway-routers/specs/routers/spec.md` (openspec change (outside the renderer, no FSD layer)) — symbols: none. The three ADDED requirements the implementation answers: a router binds in place of a target, failover walks in declared order, round-robin skips a cooling child.
- `docs/adr/0081-router-engine-parity-is-deferred-with-a-source-map.md` (docs (outside the renderer, no FSD layer)) — symbols: none. The Architecture Decision Record that deferred routing and named failover and round-robin as the two modes that open the feature.
- `packages/contracts/src/gateway-config.ts` (contracts package (shared across main, engine, and renderer; outside FSD)) — symbols: GATEWAY_CONFIG_VERSION, targetSchema, Target, virtualModelSchema, VirtualModel, gatewayConfigSchema, GatewayConfig, loadGatewayConfig. The stored gateway document, where virtualModelSchema binds exactly one target today and the router graph plus the schemaVersion bump and its migration must land.
- `packages/contracts/src/migration.ts` (contracts package (outside FSD)) — symbols: Migration, migrateDocument. The migration ladder that loadGatewayConfig runs, so the direct-target-to-router migration registers as one more Migration entry.
- `packages/contracts/src/engine-protocol.ts` (contracts package (outside FSD)) — symbols: engineVirtualModelSchema, EngineVirtualModel, engineGatewaySchema, EngineGateway, spendGrantSchema, SpendGrant. The engine's resolved view of a gateway, whose private targetStandingSchema is the bound-or-removed union that has to widen into a resolved router graph.
- `packages/contracts/src/ipc.ts` (contracts package (outside FSD)) — symbols: ipcChannels. The gateways:save, gateways:update, and gateways:list channels carry gatewayConfigSchema, so the router shape crosses IPC once the schema grows.
- `packages/contracts/src/gateway-config-targets.test.ts` (contracts package (outside FSD)) — symbols: none. The existing behavior spec for a virtual model's single target, which is the red-first home for the router-child contract.
- `packages/contracts/src/gateway-config-migration.test.ts` (contracts package (outside FSD)) — symbols: none. The migration spec that must prove a stored version-2 gateway keeps serving what it serves after the router migration.
- `packages/engine/src/gateway-request-crossing.ts` (engine package (node serving path, outside FSD)) — symbols: gatewayRequestCrossing. Resolves a virtual model name to one target and refuses when the standing is removed; the router walk and the empty-router refusal begin at this seam.
- `packages/engine/src/gateway-proxy.ts` (engine package (node serving path, outside FSD)) — symbols: proxyModelRequest, SpendGrantFor, SpendGrantContext. The single-attempt pipeline (crossing, then one spendGrantFor call, then forwardGranted) that gains the retry loop failover needs.
- `packages/engine/src/gateway-app.ts` (engine package (node serving path, outside FSD)) — symbols: createGatewayApp. Mounts every dialect route onto proxyModelRequest, so every provider path inherits the reshaped request pipeline.
- `packages/engine/src/refusals.ts` (engine package (node serving path, outside FSD)) — symbols: TranslationRefusal, missingTarget, renderRefusal, unstreamableAnswer. The typed refusal vocabulary the spec extends with an empty-router refusal and an exhausted-router refusal that name where the chain stopped.
- `packages/engine/src/gateway-answers.ts` (engine package (node serving path, outside FSD)) — symbols: answerFrom, unreachableTargetAnswer, unreachableTargetMessage. Turns an upstream outcome into a caller answer, so the retryable-versus-request-scoped split that drives failover reads from here.
- `packages/engine/src/gateway-stream-answers.ts` (engine package (node serving path, outside FSD)) — symbols: translatedStreamBody. The streaming body seam behind the rule that a router never starts another child once the answer has begun reaching the caller.
- `packages/engine/src/gateway-discovery.ts` (engine package (node serving path, outside FSD)) — symbols: modelListing, ModelListing. Derives the served model list from EngineVirtualModel, so it must keep listing a name whose target is now a router.
- `packages/engine/src/gateway-count-tokens.ts` (engine package (node serving path, outside FSD)) — symbols: proxyTokenCountRequest. Reads virtual.target.standing directly to pick a provider model, one of the side paths that must learn the router graph.
- `packages/engine/src/gateway-images.ts` (engine package (node serving path, outside FSD)) — symbols: proxyImageRequest, ImagePath. Refuses when the target standing is not bound, so the image path needs the same graph resolution as the chat path.
- `apps/desktop/src/main/engine-host/stored-gateway.ts` (main process (Electron host, outside FSD)) — symbols: engineGatewayOf, storedEngineGateway. Mints the engine's view by resolving each stored target against the account registry; a router graph is resolved child by child here.
- `apps/desktop/src/main/engine-host/spend-grant.ts` (main process (Electron host, outside FSD)) — symbols: resolveSpendGrant, SpendGrantContext. Finds the single stored target for a virtual model and resolves its credential; failover needs a grant per attempted child rather than one per request.
- `apps/desktop/src/main/storage/gateway-store.ts` (main process (Electron host, outside FSD)) — symbols: saveGatewayConfig, listGatewayConfigs, removeGatewayConfig, GatewayNewerSchemaError. Reads and writes the gateway documents that take the new version, and raises the newer-schema guard when a document outruns the build.
- `apps/desktop/src/main/ipc/gateway-storage-ipc.ts` (main process (Electron host, outside FSD)) — symbols: createGatewayStorageHandlers, GatewayStorageHandlers. The handlers behind gateways:save and gateways:update that persist the router-bearing document the canvas edits.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/lib/node-graph.ts` (pages (slice gateway-canvas, segment lib)) — symbols: CanvasNode, CanvasNodeKind, CanvasEdge, CanvasGraph, CableStanding, canvasGraph. Builds every card and cable from the stored document; the router node kind and the model-to-router-to-target cables enter the union here.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/gateway-stage/gateway-stage.tsx` (pages (slice gateway-canvas, segment ui)) — symbols: GatewayStage, CanvasFlowWiring. Holds the nodeTypes registry that maps each node kind to its component, so a router node registers here.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/virtual-model-node/virtual-model-node.tsx` (pages (slice gateway-canvas, segment ui)) — symbols: VirtualModelNode, VirtualModelNodeData. The card whose single providerModel line stops being the whole truth once a router stands between the model and its targets.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/target-node/target-node.tsx` (pages (slice gateway-canvas, segment ui)) — symbols: TargetNode, TargetNodeData. The target card that a router node sits beside and that the new node borrows its shape and handle conventions from.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/gateway-drawer/gateway-drawer.tsx` (pages (slice gateway-canvas, segment ui)) — symbols: GatewayDrawer, InspectorSubject. Dispatches the inspector body by subject kind, so the router subject and its routing-mode control join this union.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/subject-bodies/subject-bodies.tsx` (pages (slice gateway-canvas, segment ui)) — symbols: gatewayBody, modelBody, targetBody, ghostBody. The per-subject inspector bodies the drawer renders; a routerBody sibling belongs beside them.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/model-general-info/model-general-info.tsx` (pages (slice gateway-canvas, segment ui)) — symbols: ModelGeneralInfo. The virtual model inspector panel where a bound router replaces the single-target reading.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/model-fields/model-fields.tsx` (pages (slice gateway-canvas, segment ui)) — symbols: ModelFields, ModelFieldsProps. The definition form that today collects one account and one provider model per virtual model.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/ui/drop-picker/drop-picker.tsx` (pages (slice gateway-canvas, segment ui)) — symbols: DropPicker, DropPickerProps, PickerStage. The account-then-provider-model picker a released cable opens, which gains a router as a third thing a cable can meet.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/lib/model-draft.ts` (pages (slice gateway-canvas, segment lib)) — symbols: SettledDefinition, DraftBinding, gatewayDefining, gatewayRebinding, gatewayReleasing, servesPreview. The pure document edits for defining, rebinding, and releasing a virtual model's target, which now write into a graph.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/lib/tidy-layout.ts` (pages (slice gateway-canvas, segment lib)) — symbols: tidyPositions, seatForNewNode, targetSeatBeside. Seats each node kind in its column, so a router column has to take a seat between the model and its targets.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/lib/cable-standing.ts` (pages (slice gateway-canvas, segment lib)) — symbols: CABLE_GRAB_SPAN, strokeForStanding, tintForStanding, failureIn. Paints a cable from its standing, which the new model-to-router and router-to-target cables reuse.
- `apps/desktop/src/renderer/src/pages/gateway-canvas/model/served-models.ts` (pages (slice gateway-canvas, segment model)) — symbols: ServedModel, servedModels, servesTally. Derives what the gateway serves from the stored virtual models, a reading that must survive a router standing in the target's place.
- `apps/desktop/src/renderer/src/shared/ui/segmented-control/segmented-control.tsx` (shared (segment ui)) — symbols: SegmentedControl. The existing two-way control the routing-mode pill should reuse rather than reinvent, per the shared-first rule.
- `apps/desktop/src/renderer/src/entities/account/index.ts` (entities (slice account, public API)) — symbols: accountDetail. The account reading node-graph.ts already imports for target cards, and the same reading a router's children need.
- `apps/desktop/e2e/features/virtual-models/targets.feature` (end-to-end suite (outside FSD)) — symbols: none. The binding scenarios a router changes, and the natural home for the failover and round-robin acceptance scenarios.
- `apps/desktop/e2e/features/gateway-canvas/cable-wiring.feature` (end-to-end suite (outside FSD)) — symbols: none. The cable scenarios that must cover a cable meeting a router rather than only a target.
