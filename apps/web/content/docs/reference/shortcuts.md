Keys read as macOS below, and Ctrl stands in for Cmd on Windows and Linux. recompose registers no OS-global shortcuts: every key works only while the app is frontmost, and menu keys only where their menu applies.

## The basics

| Action       | Key   |
| ------------ | ----- |
| New Gateway… | Cmd+N |
| Settings…    | Cmd+, |
| Close window | Cmd+W |
| Quit         | Cmd+Q |

The home screen's empty state carries the one on-screen hint: `or press ⌘ N`.

## On the canvas

| Action                                   | Key                 |
| ---------------------------------------- | ------------------- |
| Remove the selection                     | Backspace or Delete |
| Cancel a cable drag                      | Escape              |
| Clear the selection, close the inspector | Escape              |

Delete on a card asks the canvas's removal question first, and Escape always yields to whatever owns it: a text edit, a drag, an open dialog.

## In the request log

| Action                        | Key         |
| ----------------------------- | ----------- |
| Walk the rows                 | Up and Down |
| Copy the row under the cursor | Cmd+C       |

## In fields and panels

Numeric and address fields commit on Enter and revert on Escape. Panel dividers take arrow keys to resize, Home and End to jump to the ends, and Enter to collapse or restore. Outside text fields, the arrow keys walk focus between cards and panels.
