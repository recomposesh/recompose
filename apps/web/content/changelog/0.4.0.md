recompose 0.4.0 opens on a setup wizard that carries a first session from nothing to one served request. Windows gets chrome of its own, a right-click answers everywhere it means something, and the Usage screen counts what actually crossed the wire.

## Features

- a setup wizard takes over a first session and ends with one model behind one router, ready to serve. (#326)
- Windows wears chrome drawn for Windows: its own title bar, its own clearance, and shortcuts named for its keyboard. (#314)
- a right-click answers everywhere it means something, from a text field to a card on the canvas. (#315)
- a conditional router's judge timeout is yours to set, and a stored router's default rises to thirty seconds. (#319)
- the canvas lights the whole path while a judge decides, rather than the dotted tie alone. (#318)
- a virtual model's id derives carrying the word Claude Code's picker reads for, so a model composed here reaches that picker. (#329)
- OpenCode Zen joins the aggregators catalog, priced. (#323)
- Tidy frames the whole composition after it arranges, so a press past the edge of the pane shows its work. (#309)
- a long prompt costs what its band charges, rather than the rate under it. (#324)
- the download call names the platform you are on. (#310)

## Fixes

- five gaps found in one evening on Windows close together: the sign-in code reaches the screen, a duplicate account stops landing, and the window chrome behaves. (#325)
- every cable stays drawn through a repaint, rather than leaving a composition whose bindings are all invisible. (#321)
- Usage counts what a streamed answer read, not only what it wrote. (#320)
- Usage counts tokens in the dialect that answered, so the chart and the Providers filter agree with the requests behind them. (#317)
- the Add provider screen asks the shell you actually configured, rather than offering to install what already runs. (#313)
- the device-code ask happens once, rather than again on every window focus. (#312)
- the OpenRouter credits field reads Mgmt key again. (#311)
