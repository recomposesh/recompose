recompose 0.5.0 is about what the app says when something goes wrong. A gateway that answers 502 explains itself now. A router that refused names which trouble it hit, and a restart that never came back up says so on the canvas.

## Features

- a failed request carries its whole story: the router, every target tried, why each one refused, and the provider's own error message. Select a row in the log drawer to read it, and copy the lot in one press. (#338)
- Check for Updates joins the Recompose menu, and a check you asked for reports back. The hourly one stays quiet, the way it always did. (#338)
- every icon-only control says what it does when you rest on it, in the same words a screen reader hears. (#338)
- Codex signs in through recompose itself, so a plan you pay for no longer waits on you installing the Codex command line. (#338)
- a connect block hands over one command you can run, with the variables in front of it, so nothing outlives the session you started. (#338)
- a branch rule says out loud that it's a prompt, shows an example, and opens for editing from the branch you're looking at. (#338)
- the sidebar carries the brand on macOS too, where the corner beside the traffic lights used to sit empty. (#338)

## Fixes

- live cables flow again on machines that ask for reduced motion. The bead stood down with the travel, which took the only mark that says a request is moving. Linux met this most, because one desktop setting turns it on without anyone asking. (#338)
- setup no longer hangs on a source that answers nothing. A model list the app couldn't read looked exactly like one still arriving, so the wizard span with no way out but abandoning it. It now says which account went quiet and offers to try again. (#338)
- the first model setup picks for you is one the provider still serves. The old ranking preferred a model already announced for shutdown. (#338)
- a conditional router that reached no verdict names which of four things happened, rather than handing every cause the same sentence. (#338)
- Select all in the Usage filters does what it says. The filter reads as every member checked while it stands on everything, and letting one go keeps the rest. (#338)
- a window opened mid-request sees the traffic already in flight, rather than waiting for it to finish. (#338)
- Move to another port is now Change port, and Use this account went away. Choosing an account moved a pointer nobody could see, so the account your terminal reaches is simply the one you signed in last. (#338)
