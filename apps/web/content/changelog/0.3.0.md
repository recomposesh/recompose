recompose 0.3.0 is the first public release. the app runs a local gateway with its own engine, treats provider subscriptions as accounts it manages for you, and installs on macOS, Windows, and Linux.

## Features

- the first gateway arrives, with the engine that serves it. (#105)
- a canvas composes that gateway: the cards you wire are the configuration, never a picture of it. (#151)
- a virtual model publishes one name to clients, and what stands behind the name stays yours to rewire. (#144)
- routers pick the target per request: failover, round-robin, and a conditional router whose judge reads the request and names the branch. (#214, #269)
- provider subscriptions become managed accounts: sign in once, and every gateway can route through that account. (#116, #240)
- recompose adopts the plans already signed in on the machine, and every request says which account it spends. (#180, #210)
- API keys become managed accounts too, across every provider the catalog names, aggregators and local runtimes included. (#127, #134, #181)
- the Usage page totals every served request by gateway, provider, and model, with quota cards that say what each plan has left. (#164, #257, #278)
- a gateway carries an optional key, moves to another port, and hands any client its address from the toolbar. (#189, #203, #242)
- the request log keeps every answer the gateway refused, beside the ones it served. (#260)
- the app updates itself through the channel that installed it. (#248)
- the menu bar takes its shape from the platform, with a Dock menu and shortcuts that update live. (#246)
- one homebrew cask serves Apple Silicon and Intel from the same command. (#250)
- the settings screen lands. (#94)
- the sidebar gains its own control, its own edge, and a way out. (#115)
- the desktop shell opens with liquid glass window chrome on macOS. (#14)
